# Final Fantasy VII

Europe, Disc 1, SCES-00867. [game.toml](game.toml) identifies the tested revision and records the 12,051-frame route from reset, with empty memory-card slots, through New Game, the opening movie and the first field dialogue with Cloud. This is the supported and verified scope; later battles, normal saving/loading, disc-change requests and the rest of the game remain unverified for this title.

The opening initially became gray because the runtime discarded uploaded MDEC quantization and scale tables on a control reset. After retaining them, zero-time decoding still let the game overwrite its movie buffer before queued GPU uploads consumed it, repeating the first three columns. The shared decoder now preserves the tables and schedules output availability and completion. Processing time is an explicit approximation based on public console measurements; exact RLE-dependent latency, pipeline overlap and IDCT rounding remain open. [Development](../../docs/development.md#phase-2-hardware-breadth) records the evidence and synthetic regression checks.

The local build agrees with the interpreter at all 97,145,525 comparison stops through the opening field dialogue, with 93.35% of CPU instructions native under the earlier capture. The longer capture route is now the profile's build default. Metal 1× agrees with software VRAM/cache on all 9,500 frames through the train shot, with the same picture hash. A separate 600-frame movie window using the production AudioQueue adapter produces nonzero audio throughout, without empty-queue events or ring overflow. These checks cover the stated routes and window, rather than whole-game visual or audio accuracy.

On 2026-11-06 the user confirmed that the gray screen and repeated columns were corrected and the game was working. The [gallery screenshot](../../docs/images/final-fantasy-vii.png) shows the first field dialogue; [capture provenance](../../docs/images/README.md#final-fantasy-vii) identifies the exact local build. The three-disc app remains available locally, but this does not establish story-ending handoffs or later-disc gameplay. Game files, generated code, checkpoints, cards and comparison captures stay outside the repository.
