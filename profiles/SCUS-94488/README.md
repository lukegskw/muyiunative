# Gran Turismo 2 — Simulation Mode

USA v1.2, SCUS-94488. [game.toml](game.toml) identifies the supplied disc and records a 9,000-field route from reset, with empty memory-card slots: Start Game → Go Race → GT League → Japan Nationals → the first Midfield Raceway replay, featuring the Suzuki Alto Works RS/Z '98. All 2,944,191,223 instructions execute natively and agree with the interpreter over 71,531,402 lockstep stops. The earlier 6,000-field attract replay remains under `attract`.

This route was used to investigate a player's report that audio stuttered and stopped with Metal. A busy Metal 4× frame exhausted the host playback reserve; the Mac adapter now suspends and refills its existing buffers before resuming. The correction applies to every game. Measurements and their limits are recorded in [Development](../../docs/development.md#playback-recovery-after-metal-stalls).

The confirmed Midfield replay exposed further rendering bottlenecks: thousands of small textured triangles repeatedly synchronized device memory, and per-sample arithmetic used wider integers than its final result requires. Batches now use threadgroup memory; rasterization and exact modular interpolation use 32-bit arithmetic. In a 1,200-field close-up window, measured 4× busy-field GPU time fell from 35.6 to 22.9 ms on the test Mac, preserving the fine-image hash. The initial cache optimization also reduced physical audio reserve exhaustion from 12 to two occurrences in a separate paced window, with zero ring drops and exact stereo submission order. A later headless physical-audio retest could not start because `AudioQueueStart` failed on both local outputs. Some individual fields still exceed the 30-fps budget, and uninterrupted playback on the original reporter's M1 Max remains unverified. See [the replay investigation](../../docs/development.md#gt2-midfield-replay-performance).

On 2026-11-04 the user retested the updated app and confirmed that the reported playback and rendering problems were resolved. This acceptance covers the reported Go Race → Replay path and Metal 2×/4× settings; it does not establish whole-game compatibility. Automated checks did not independently reproduce the original disappearing faces/stretched triangles. An isolated packet replay reproduces the sampled scene's geometry in an external emulator used only as a black box; that comparison does not validate the game's CPU/GTE vertex calculation.

Normal memory-card saving, controllers, completed events, later scenes and whole-game audible accuracy remain unverified for this disc. Local captures, compiled game code and checkpoints stay outside the checkout.
